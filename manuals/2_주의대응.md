# 2. 주의 대응

## 판정 기준
ci_lower가 **20.7 사이클 초과 50.25 사이클 이하**이면 "주의" 등급으로 판정한다. YELLOW_THRESHOLD(50.25)는 같은 실측 분포의 25th percentile 값이다. RUL=0은 flank wear(VB)가 교체 기준 0.3mm(ISO 8688-2, ISO 3685)에 도달한 시점에 해당하므로, 주의 등급은 마모가 진행 중이지만 아직 여유가 있는 상태다.

## 표준 조치
- 향후 **N=10사이클 이내** 교체 완료를 목표로 일정을 확정한다.
- 모니터링 절차(4부)의 "집중 모니터링"을 병행한다.

## 참조 섹션
- 4부(모니터링 절차): 참조 (집중 모니터링)
- 6부(교체 부품 정보): 참조 (교체 대비)
- 7부(정비 절차): 해당 없음 (아직 교체 시점 아님)
- 8부(소요 시간): 해당 없음 (아직 교체 시점 아님)
